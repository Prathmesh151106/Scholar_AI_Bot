# 🎓 Scholar AI Bot

An interactive, voice-activated AI study companion built with Python. Scholar AI Bot leverages the **Google GenAI SDK** (`gemini-flash-lite-latest`) to deliver fast, concise academic explanations and uses **pyttsx3** for offline text-to-speech audio responses.

---

### ✨ Features
- ⚡ **Powered by Gemini Flash Lite:** Fast, reliable, and context-aware responses using chat sessions.
- 🗣️ **Voice-Enabled:** Speaks out answers clearly using `pyttsx3`.
- 🕒 **Smart Greetings:** Greets the user based on the current time of day.
- 🎯 **Concise & Academic:** Optimized system instructions tailored for quick study revision.

---

### 🛠️ Tech Stack
- **Language:** Python 3
- **AI Model:** Google Gemini (`gemini-flash-lite-latest`)
- **SDK:** `google-genai`
- **TTS Engine:** `pyttsx3`
